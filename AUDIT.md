## Проверено и в порядке (без замечаний)

* **XSS.** Весь пользовательский текст (ники, рейтинг, ИИ-заметки, чат, имена в лобби) попадает в DOM только через `textContent`; `innerHTML` используется со статическими шаблонами. Проверено e2e: чат с `<img onerror>` не исполняется.
* **Инъекции.** SQL — только параметризованные запросы; CSV-экспорт экранирует `= + - @`; заголовки ответа не содержат пользовательских данных.
* **SSRF в ИИ-провайдерах.** Адреса провайдеров зашиты в код (белый список хостов), `follow_redirects=False`, пользовательский ввод — только ключ и модель; пробный запрос идёт на `/models` определённого по сигнатуре хоста.
* **Секреты.** Пароль админки — scrypt; сессии — HMAC-подпись + CSRF + `SameSite=Strict`, `__Host-` префикс; ключи ИИ — Fernet, наружу только маски; `.env` и `.steam_secrets` вне репозитория (проверено поиском по истории).
* **CORS.** Заголовки `Access-Control-*` только на публичных путях `/api/g/*` и только для разрешённых origin; админка недоступна напрямую (403 без Worker-секрета). WebSocket (не проходит HTTP-middleware) проверяет `Origin` отдельно: разрешены `pages.dev` и `github.io`, всё остальное, `null` и пустой — отказ.
* **Рейтинг.** Один результат на игрока, ограничения по IP/минуту/сутки, проверка правдоподобия времени, билет прохождения подписан HMAC, IP хранится только суточным хэшем.
* **Утечки.** Ответы об ошибках без трассировок; `Cache-Control: no-store`; логи без IP и тел запросов.

## Угрозы мультиплеера (дизайн и меры)

| Угроза | Мера |
|--------|------|
| Подделка результата кооператива | Авторитетный сервер: клиент шлёт только команды; результат считает сервер; в рейтинг кооператив не пишется (веха 1) |
| Управление чужим клапаном | Права по ролям на сервере, `forbidden` без побочных эффектов |
| Мусорные значения (`NaN`, большие числа, `__proto__`) | Валидация в ядре и протоколе; JSON-объекты как данные, не как код; тест на «prototype pollution» |
| Флуд сообщениями/соединениями | token-bucket 40 сообщений/с, ≤2 КБ на сообщение, ≤8 соединений на IP, ≤3 новых комнат на IP за 10 мин, ≤200 комнат, потолок очереди исходящих (медленный клиент отключается) |
| Захват чужого места | `rejoin` только с секретом (24 символа, `hmac.compare_digest`), старое соединение вытесняется |
| Чужой сайт открывает WebSocket от имени игрока | Проверка `Origin`; авторизации по cookie нет — нечего угнать |
| Чат: HTML, ссылки, невидимые символы | NFKC, удаление управляющих/невидимых, ≤120 символов, ссылки/почты/домены отклоняются, вывод через `textContent`; эмодзи — белый список кодов |
| Зависшие/брошенные комнаты | Лобби 15 мин, окончена 10 мин, потолок жизни 2 ч, пауза при потере связи ≤60 с, затем место освобождается |
| Нагрузка | Шаг симуляции ≈ десятки микросекунд; один процесс; замеры нагрузки не проводились (см. MULTIPLAYER.md) |
