# Changelog

## 1.1.1 (2026-10-02) — «не грузится на телефоне»

Жалоба: на телефоне игра «вообще не грузится». Воспроизвести на эмуляции (Android Chromium, iPhone WebKit, медленная сеть, `/api/*` оборван/завис/500/401) не удалось — игра стартует за доли секунды. Нашлось и исправлено то, что могло давать чёрный экран и «ничего не нажимается»:
- **Звук мог ломать игру.** Исключение при создании/запуске AudioContext (iOS/WebKit: `InvalidStateError: Failed to start the audio device`, отсутствие узлов WebAudio, отклонённый `resume()`) всплывало из обработчика нажатия *до* вызова действия кнопки — «Новая игра» молча не срабатывала. Теперь любая ошибка звука глотается, звук отключается, игра идёт без него.
- **Один файл вместо цепочки из 12 модулей** (`type="module"`): на мобильной сети любой потерянный файл ломал запуск, а устаревшие закэшированные части (`/src/*` кэшировались на 5 минут) могли не совпасть с новой страницей. Теперь прод — один классический скрипт `game.<хеш>.js` с пониженным синтаксисом (Safari 11+/Chrome 64+/Firefox 60+/Edge 79+), имя файла содержит хеш (кэш «навсегда», рассинхрона быть не может).
- **Страж загрузки `boot.js`** (ES5, первым в странице): любая ошибка до готовности игры, не загрузившийся файл или поток ошибок во время игры → экран «Игра не смогла запуститься» с кнопками «Перезагрузить» и «Сбросить сохранение и перезагрузить» вместо чёрного экрана; если игра не готова за 8 с — мягкая подсказка о слабой связи.
- **Сеть не может задержать игру**: жёсткий лимит 3 с на любой запрос к бэкенду (`AbortController` + гонка с таймером на случай браузеров, где fetch не отменяется); `_worker.js` отдаёт 504 за 2,5 с, если бэкенд завис.
- Мелочи совместимости: `replaceChildren` заменён на `textContent = ''`.
- Тесты: `tests/compat/boot.pw.js` (Android Chromium + iPhone WebKit; 6 сетевых сценариев и 8 аварийных: сломанное сохранение, `localStorage` бросает, звук падает, нет современных API, файл игры не загрузился/бросает/синтаксическая ошибка), `tests/net.test.mjs` (3 с), `tests/bundle.test.mjs` (ES2017/ES5). Playwright-тесты можно запускать на собранной версии: `SEG_SITE=dist`.

## 1.1 (2026-10-02)

### Исправлено
- **Манометр**: наложение «ДАВЛЕНИЕ/атм» на отметки 0 и 100. Теперь на циферблате только отметки шкалы и слова «ДАВЛЕНИЕ», «атм»; раскладка вынесена в `gaugeLabels()` и проверяется на пересечения. Портретный манометр чуть крупнее (r 76 → 84).
- **Дым**: удалён второй шлейф (фабричный дым силуэта города, а при «буром угле» — ещё один из трубы). Остался один шлейф из трубы котла; рисуется под HUD, не залезает на «УГОЛЬ/ЖИТЕЛИ». Шлейф стал компактнее и реже.
- **Звук**: ползунок «Громкость» управлял и музыкой. Теперь «Звуки» и «Музыка» — независимые узлы gain (master — только выключатель «Звук включён»), логарифмическая кривая 40 дБ, ноль = тишина; старая настройка `vol` мигрирует в `sfx`.

### Добавлено
- Онлайн-рейтинг (по очкам и по выживанию), необязательный ник, билеты прохождения, серверная проверка правдоподобия, лимиты.
- Анонимная статистика сессий + переключатель в настройках (включён по умолчанию, честно описан).
- Админка (`/admin`): вход на Pages, панель от бэкенда только после авторизации; сессии, фильтры, агрегаты, рейтинг (скрыть/удалить), CSV.
- Бэкенд `backend/` (FastAPI + SQLite), `_worker.js`, systemd/nginx.
- Мобильная версия: safe-area, цели касания ≥ 44 px, зоны нажатия паузы/утечек на мелком масштабе, `touch-action`, адаптивные оверлеи для низких ландшафтных экранов, ограничение DPR на телефонах, разблокировка аудио по первому касанию.
- Режим ускорения `?speed=` теперь работает только вместе с `?debug`.
- Тесты: звук (мок + OfflineAudioContext), счёт (общие векторы JS↔Python), бэкенд (pytest, 43), Playwright e2e (рейтинг/админка, мобильные/десктопные вьюпорты).

### Известные ограничения
- Проверка на мобильных — эмуляцией в headless Chrome; на реальных телефонах (iOS Safari, Android Chrome, вырезы, жестовые панели, производительность) не проверялась. Safe-area проверена эмуляцией через CSS-переменные.
- В альбомной ориентации телефона сцена масштабируется целиком (≈ 0.56 при 844×390): мелкий текст HUD читается хуже, интерактивные элементы увеличены по зоне нажатия, но не по виду.
- Накрутка рейтинга полностью невозможна только с серверным симулятором; текущие проверки отсекают тривиальные подделки и спам (см. README).
